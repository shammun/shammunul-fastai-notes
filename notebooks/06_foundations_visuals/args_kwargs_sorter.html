Mnemonic: count the stars. * = one row of values (a tuple/list) · ** = two-part pairs, name=value (a dict). In a def they catch (many → one container); in a call they throw (one container → many slots). That pass-through trick is exactly how cb(*args, **kwargs) forwards everything in fastai callbacks.
