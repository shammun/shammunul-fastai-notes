Same machine, three ways to build it. A lambda writes the wrapper inline; a closure is a factory whose inner function remembers the exclamation; partial asks Python to build the wrapper for you. In all three, the purple value is baked in once (step 1!), and the orange i flows through on every epoch — which is exactly why cb(i) with one argument is enough.
