A Callback That Changes the Calculation

Because SlowCalculator passes itself (self) to its callbacks, the callback can read and write calc.res. Step through — or click any epoch's bars to jump straight to it.

The code (what runs each epoch)

# inside SlowCalculator.calc():for i in range(5):    self.res += i*i    if self.callback('after_calc', i):        print("stopping early"); break# inside ModifyingCallback:def after_calc(self, calc, epoch):    print(f"After {epoch}: {calc.res}")    if calc.res > 10: return True  # stop!    if calc.res < 3:  calc.res *= 2  # modify!

Why this matters: this is exactly how fastai callbacks implement LR schedulers, gradient clipping and early stopping — by reaching into the trainer's state from outside, without editing the training loop. Toggle the callback off and replay to feel the difference.
