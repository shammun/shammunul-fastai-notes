Callback Playground

A callback is a function you hand to other code, so that code can call you back when something happens.

1 · The GUI analogy click freely

A button doesn't know what should happen when it's clicked — you tell it by registering a callback. Flip the switch, then click the button and watch the signal travel down the wire.

def f(o): print('hi')
# click log appears here…

Unchecked: clicking does nothing — no callback is registered. Checked: every click travels down the wire into f, which prints hi. You wrote f; the button decides when to run it. That division of labor is the callback idea.
