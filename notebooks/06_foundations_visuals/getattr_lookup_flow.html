__getattr__: The Attribute Lookup Safety Net

When you write b.something, Python walks a fixed lookup path. __getattr__ is called only when every normal step fails. Pick an attribute, then step through the walk — or click any box in the flowchart to jump to that moment.

class B:    a, b = 1, 2          # real (class) attributes    def __getattr__(self, k):        if k[0] == '_':            raise AttributeError(k)        return f'Hello from {k}'

Why this matters: __getattr__ is how libraries make attributes appear out of thin air — fastai delegates self.learn.model through it, pandas resolves df.colname, PyTorch finds submodules. The underscore guard keeps Python's internal _/__ probes from getting fake answers.
