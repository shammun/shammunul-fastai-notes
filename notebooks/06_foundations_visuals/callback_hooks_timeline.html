Hooks, hasattr Gates & Early Stopping

The loop offers two hook points per epoch; whether each fires depends on its gate: if cb and hasattr(cb, '…'). If after_calc returns True, the loop stops. Click any node, gate or epoch label to jump to that exact moment.

The two pieces of code

the loop (never changes)
def slow_calculation(cb=None):    res = 0    for i in range(5):        if cb and hasattr(cb,'before_calc'):            cb.before_calc(i)        res += i*i; sleep(1)        if cb and hasattr(cb,'after_calc'):            if cb.after_calc(i, res):                print("stopping early"); break    return res
