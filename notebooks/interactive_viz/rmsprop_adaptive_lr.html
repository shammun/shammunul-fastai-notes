RMSProp — every parameter gets its own learning rate

One global lr must serve millions of parameters — but some see huge gradients and some see tiny ones. RMSProp tracks an EMA of each parameter's squared gradient and divides by its square root: p −= lr · grad / (sqr_avg.sqrt() + eps). Big-gradient parameters get tamed, small-gradient parameters get amplified. Walk the rail, then press Race ▶.
