KID: compare clouds directly — no Gaussian assumption

KID skips μ and Σ. Instead it asks: are points within each cloud about as similar to each other as points across the clouds? Similarity = a polynomial kernel k(a,b) = (a·b/d + 1)³. We build three similarity tables — real↔real, gen↔gen, real↔gen — then MMD² = (within-similarity) − 2·(across-similarity). Hover any cell to see the exact pair and value.
