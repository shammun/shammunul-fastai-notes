The ResBlock Machine

A ResBlock computes output = act( convs(x) + shortcut(x) ). The tensor splits into the conv path (learns the residual F(x)) and the shortcut path (keeps x reachable). Click any stage — the matching line of forward() lights up — or click a box in the diagram to jump there.
