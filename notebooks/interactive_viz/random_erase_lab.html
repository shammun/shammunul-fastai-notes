Random Erase (Cutout) — the model can't rely on any single region

A rectangle of the image is destroyed and refilled with gaussian noise that has the same mean & std as the data — so the image "looks statistically normal" to BatchNorm, but the sneaker's toe (or collar, or heel) is gone. If the model was leaning on that one region, it now has to learn the others too. Each stage below is one line of the notebook's _rand_erase1. Click the image to place the patch yourself.

Why noise, not black? the statistics stay matched

Erasing with zeros would shift the batch statistics (mean drops, BatchNorm gets confused). Erasing with data-matched noise keeps mean/std ≈ unchanged — the notebook computes xm, xs, mn, mx from the batch for exactly this reason.
