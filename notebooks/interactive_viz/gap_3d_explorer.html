Global Average Pooling — every feature map is squeezed into ONE number

After the last ResBlock, x is a stack of C tiny images ("feature maps"), one per channel — in the real notebook [512 channels × 2 × 2] (here C is small and maps are 4×4 so you can see them). GAP simply averages the 16 pixels of each map into a single number, turning the whole stack into a short vector of C numbers — the perfect input for a small Linear(C, 10) classifier.
