Read it as: diffuse (spread to neighbors via the Laplacian), react (u + 2v → 3v), feed new u, kill some v. Each cell only ever sees its 3×3 neighborhood — exactly like an NCA cell — yet coherent structure appears at the scale of the whole dish. That gap between the size of the rule and the size of the pattern is emergence.
