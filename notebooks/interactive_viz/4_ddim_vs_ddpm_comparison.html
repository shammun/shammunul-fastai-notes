Practical impact — 3 runs from the SAME initial noise tensor
η = 0 — fully deterministic. No z term exists. Same starting noise → the exact same final image, every run. Good for: reproducible outputs, interpolating between two noises, image editing via inversion.
0 < η < 1 — interpolation. Partial randomness: runs from the same noise come out similar but not identical. A balance dial between reproducibility and variety.
η = 1 — equivalent to DDPM. σt carries DDPM’s full variance (a computed fact — see the σ page): same noise → a different valid image each run. Maximum variety.
Why DDIM is faster — the four-point verdict
🚫🎲
1 · No accumulated randomness. DDIM (η=0) never rolls the dice, so there is no per-step variance that must be accounted for — the “variance explosion from skipping” simply has nothing to explode.
🔖
2 · Endpoint-only math. The update uses the cumulative ᾱ values of the two timesteps involved — nothing about the steps in between. Any gap size is equally legal: t → t−1 and t → t−100 use the same formula.
📍
3 · Determinism = predictability. With one fixed trajectory per starting noise, visiting fewer waypoints still traces the same route — fewer steps approximate the same curve rather than a different random walk.
🎓
4 · Same training. Both samplers consume the identical εθ checkpoint. DDIM is purely an inference-time upgrade — you can bolt it onto any trained DDPM today.
