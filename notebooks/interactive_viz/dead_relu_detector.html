Dead ReLUs: when neurons get stuck at zero

ReLU outputs max(0, x). If a neuron's pre-activation is almost always negative, ReLU outputs 0 every time — the neuron is "dead" and learns nothing. Move the sliders to push the input distribution negative and watch the dead fraction climb.

def get_min(h):

    return h1[0] / h1.sum(0)   # bin-0 count ÷ total = dead fraction
