Why augment? The overfitting gap — opened, then closed

Without augmentation the notebook saw train 99.9% vs valid 92.4% after 20 epochs — the model memorized the training pixels instead of learning clothing shapes. Drag the augmentation strength slider and press ▶ to re-run training: augmentation makes memorization impossible (the pixels keep changing!), so the model is forced to learn general features — the gap shrinks and validation accuracy climbs.

Press ▶ Train to run 20 epochs with the chosen augmentation strength. Try 0% first, then ~50%, then 100%.
💡 Why it works: with random crop + flip there are ~162 versions of every image. The network can't memorize a moving target, so the only way to reduce training loss is to learn features that hold for all versions — and those generalize. (Note the trade: train accuracy drops. That's fine — validation is what we ship.)

orange = train · teal = validation · red band = the gap. Too much augmentation can also hurt (try 100%): the task gets artificially hard. Tune it like any hyper-parameter.
