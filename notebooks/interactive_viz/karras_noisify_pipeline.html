# noisify(x0) — the training-pair factory (verbatim logic from this notebook) def noisify(x0): sig = (torch.randn([len(x0)]) * 1.2 - 1.2).exp().reshape(-1,1,1,1) # ② log-normal σ noise = torch.randn_like(x0) # ③ fresh Gaussian noise c_skip, c_out, c_in = scalings(sig) # ⑤ the three dials noised_input = x0 + noise * sig # ④ corrupt the image target = (x0 - c_skip * noised_input) / c_out # ⑥ NOT noise, NOT clean — the blend return (noised_input * c_in, sig.squeeze()), target # ⑦ (input, σ), target

orange = what the network receives  •  teal = what it must output  •  purple = the σ-dependent dials. The three left panels share ONE grayscale scale, so the + and = are literally true on screen (at high σ the clean image fades — that's honest: the noise really does dwarf it). Target & network input share a std-1 scale.
