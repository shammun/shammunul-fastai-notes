Why .reshape(-1, 1, 1, 1)? Indexing alphabar[t] gives one number per image — shape (4,). But the images are (4, 1, 28, 28). Adding three size-1 axes lets broadcasting stretch each image’s single ᾱ value across all its 784 pixels:
(4,) — reshape → (4, 1, 1, 1) × (4, 1, 28, 28) = (4, 1, 28, 28)
