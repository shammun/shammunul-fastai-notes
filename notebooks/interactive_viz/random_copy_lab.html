Random Copy — paste a patch of the image over another patch

Same "hide a region" idea as Random Erase, but instead of noise, the hole is filled with real pixels copied from elsewhere in the same image. The occluding pixels are perfectly in-distribution — same texture, same brightness — so nothing about the image statistics changes at all. Stages map to the notebook's _rand_copy1. Click once on the image to choose the source, click again for the destination.

Erase vs Copy — what's the difference?

Erase: fills with noise → statistics approximately preserved (needs xm, xs, clamp).
Copy: fills with the image's own pixels → statistics exactly preserved, zero bookkeeping. The occluder even has realistic texture.
Both teach the same lesson: no single region is guaranteed to survive, so spread your attention.

Careful reading of the notebook code: x[stx1…] = x[stx2…] — region 1 is written (destination), region 2 is read (source). The copied patch can even overlap the source.
