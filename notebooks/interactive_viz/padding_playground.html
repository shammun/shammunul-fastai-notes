"Same" padding: why padding = ks // 2 keeps the size

A stride-1 convolution normally shrinks an image, because the kernel can't hang off the edge. Adding a border of zeros — padding = ks//2 — gives the kernel room to start in the corner, so the output comes out the same size as the input. Slide the controls and watch the math resolve.
