How to read the scene

The ten boxes ARE the tensor at each stage (click one!): face size = spatial grid (32×32 … 4×4), thickness = channels (1 … 256). Left arm = encoder going down, bottom = bottleneck, right arm = decoder coming back up. The purple sphere below is the timestep t — dashed risers feed it into every block.
orange box = the batch (its label tracks the shape) · brightened blocks = already visited · teal packet = a saved skip copy riding its dashed highway, waiting to be concatenated · purple riser pulse = the t-embedding entering each block · in and out are both 1@32×32: the output is the predicted noise ε̂, not an image.
