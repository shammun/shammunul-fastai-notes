Where should noisify live? — the data pipeline, animated

The same math can run in two very different places. Callback mode (Section 5) noisifies on the main process, after the batch reaches the GPU queue. Collate mode (Section 7) pushes it into collate_ddpm, so 4 background workers noisify in parallel while the GPU trains. Toggle modes, add MultDL ×2 (Section 9), and watch the batches (■) flow.
