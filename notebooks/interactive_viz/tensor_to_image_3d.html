An image tensor in 3D: pixels → grid → flat row of 784

A Fashion-MNIST image is a [1, 28, 28] tensor — 1 channel, 28 rows, 28 columns. Each pixel's brightness is drawn here as a 3D bar. Watch how flattening unrolls the 28×28 grid into one long line of 784 numbers — and why we can always fold it back. Drag to rotate, scroll to zoom.

Key insight: flattening doesn't change the numbers, only their shape. The same 784 values can be a flat vector for a linear layer or be folded back to [28,28] for show_image to draw. Order is preserved: row 0 first, then row 1, and so on.
