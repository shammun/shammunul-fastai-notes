NLL loss = −log(p of the correct class)

Drag the model's predicted probability p for the true class. The loss is gentle when the model is confident and right, and explodes as the model becomes confidently wrong.

p(correct class) = 0.10
loss = −log(0.10) = 2.30

Landmarks: p = 1.0 → loss 0 (perfect). p = 0.1 → loss 2.30 — exactly what an untrained 10-class model scores by random guessing, which is why our first training report starts near 2.3. p → 0 → loss → ∞, so the gradient pushes hardest on the most embarrassing mistakes.
