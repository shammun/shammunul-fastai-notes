Sampler Playground: Watch Euler, Ancestral, Heun & LMS Actually Sample

The teal blobs are the “dataset” (a 3-cluster toy distribution) whose ideal denoiser D(x,σ) we can compute exactly — so this is real diffusion sampling, not a cartoon. Particles start as orange pure noise at σmax and must land on the data. Switch samplers, change the step count, add ancestral noise (η) or Heun churn, and click anywhere on the σ progress bar to jump to that stage — the line of code being executed lights up on the right, and the purple bar under the canvas narrates each line in plain words while the canvas acts it out (the key at the bottom of the card decodes every mark). Want finer control? ⏵ Substep advances one code line per click, fully self-paced. Click on the canvas to drop an extra particle.

Things to try: with only 4–6 steps, compare Euler's straight-line hops with Heun's gently bent segments (Heun evaluates the slope twice per step — that's what “2nd order” looks like; on real images this shows up as sharper results per model call); Ancestral with η=1 (jittery paths, more diverse endpoints) vs η=0 (collapses to plain Euler); LMS order 1 (=Euler) vs order 4 (smoother with the same model calls).
