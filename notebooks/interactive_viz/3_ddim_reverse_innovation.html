DDIM’s key innovation: one update rule, three superpowers

DDIM defines a non-Markovian reverse process that keeps the same forward process and the same trained model, yet gains three abilities: it can be made deterministic (η = 0), its variance stays correct for any η, and it can skip timesteps without breaking the math. Three tabs, one per superpower — every number computed live from the notebook’s real schedule.

The variance guarantee (doc: “total variance is correct regardless of η”)
🧠 Why “non-Markovian”? A Markov step may look only at the previous state xt. DDIM’s step consults x̂₀(xt) — an estimate of the original image — so information flows from the far past into every step. That extra reference is what unlocks determinism and skipping, while the training objective (predict ε) stays untouched.

The ᾱ lookup table — grey entries are never touched
The doc’s claim, made visible: DDIM’s update uses only the cumulative levels ᾱt and ᾱs of the steps you actually visit (lit purple). Nothing about the grey intermediate entries enters the computation — which is why any jump size is legal. DDPM’s per-step variance βt is defined only for adjacent steps, so its chain cannot be cut.
