How @with_cbs('batch') Wraps a Method

The decorator turns one line — your _one_batch — into a sandwich: fire before_batch, run your code, fire after_batch, and if a CancelBatchException pops out, swallow it quietly. Step through to watch control flow through the layers. Try the Normal vs Cancel run.

Why a decorator and not a context manager? Because contextlib.contextmanager can't cleanly let a callback cancel before the yield. The decorator version catches the matching Cancel…Exception by name, so each loop level (batch / epoch / fit) can be stopped independently.
