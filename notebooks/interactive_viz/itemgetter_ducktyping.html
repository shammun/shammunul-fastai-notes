itemgetter: build a reusable getter — and why duck typing makes it work anywhere

Pick the keys you want to pull out. itemgetter bakes them into a small function ig that returns a tuple in that order. The twist: ig never checks the type of what you pass it — it only needs square-bracket access. So it works on a real dict and on any custom object that defines __getitem__.

Choose which keys ig should grab (order matters):
ig = itemgetter('a', 'c')

d = dict(a=1, b=2, c=3) dict

→

ig(d)

(1, 3)

  

  
Duck typing: "if it walks like a dict and quacks like a dict…" — Python doesn't care that D() isn't a real dict. Because D defines __getitem__, the very same ig works on it unchanged. That's how one tiny getter can power collate_dict on Hugging Face batches.
