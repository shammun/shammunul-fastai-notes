Zoom out: the whole dataset diffusing, not just one image

Every point is one image squashed to 3 coordinates (real images live in 32×32 = 1024-D; same idea, drawn where we can see it). The dataset isn't a blob — it has structure: here, two classes forming two ribbons. Forward diffusion melts that structure into one featureless Gaussian ball — and because every dataset melts into the same ball, sampling can start from plain torch.randn.
