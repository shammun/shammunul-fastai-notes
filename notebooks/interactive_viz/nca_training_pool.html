Training an NCA — why we keep a pool of 256 evolving grids

If we always trained from blank grids, the NCA would only learn to start textures — it would never learn to keep them stable for hundreds of steps. The fix: a pool of 256 grids that persist across iterations. Each iteration we grab 4, evolve them a random 32–96 steps, score them with the style loss, take a gradient step, and put them back — so later iterations see grids that are already 1000s of steps old.
