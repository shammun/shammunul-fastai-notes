with Hooks(model, _print_shape) as hooks: learn.fit(1) never calls print on our layers directly. Instead it works like notifications: 🔔 subscribe to every module → get pinged automatically each time a module runs → 🧹 unsubscribe when done. 🧠 Mental model: YouTube notifications — ① hit 🔔 subscribe · ② get pinged automatically on every new video (you never poll the channel) · ③ unsubscribe when done. Forgetting ③ = pinged forever = the classic hook memory leak.
