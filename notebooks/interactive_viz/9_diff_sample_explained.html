🔁 Same function, same model, same noise schedule — only the scheduler object and
    its step count change. That is DDIM’s core promise: swap the sampling algorithm without retraining.

    
⚠️ The one critical requirement: the scheduler’s beta_end must
    match the training schedule — 0.01 here. A mismatched schedule means the model’s noise
    predictions are calibrated for different ᾱ values, and quality collapses.

  





  
Summary

  

    
ASPECTDETAIL

    
PurposeGenerate images via reverse diffusion using any HuggingFace scheduler

    
OutputList of progressively denoised images — the final samples are preds[-1]

    
Key designScheduler-agnostic: the loop is decoupled from the denoising algorithm (DDPM, DDIM, DPM-Solver, UniPC, …)

    
Model callsOne U-Net forward pass per timestep visited

    
SpeedDetermined entirely by len(sched.timesteps), set via sched.set_timesteps(n)
