Shuffling happens to the indices, never to the data itself — the dataset stays put on disk/memory and the sampler just visits it in a new order each epoch. Toggle drop_last to see the ragged final batch get discarded (handy when a layer like BatchNorm dislikes tiny batches). Untick shuffle to get the sequential order you'd use for validation.
