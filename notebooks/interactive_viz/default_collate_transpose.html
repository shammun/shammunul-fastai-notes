From a list of dicts to a clean (xb, yb) tuple

A Hugging Face batch arrives as a list of per-sample dicts, but the training loop wants a tuple it can unpack. Two tools chained together do the job: default_collate groups-and-stacks by key, then itemgetter reads the values out in order. Step through to see exactly where the transpose happens.

The transpose in one phrase: the data goes from "a list, where each item is a dict" to "a dict, where each value is a stacked column." default_collate does that pivot; collate_dict just adds itemgetter(*ds.features) on top so you get a tuple in feature order.
